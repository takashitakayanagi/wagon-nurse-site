# public/images/manga に配置する漫画画像（模試LP）

漫画のコマ画像をここに置いてください。**画像が1枚も無い状態でもLPは完成しています。**
未配置のコマは「漫画画像は準備中です」というプレースホルダーになり、
レイアウトは崩れません。絵ができたら、このフォルダに置くだけで差し替わります。

## ファイル名（`src/config/site.ts` の `mangaSlides` に対応）

```
manga-01.webp
manga-02.webp
manga-03.webp
manga-04.webp
manga-05.webp
manga-06.webp
```

## 各コマの内容（config の alt と対応。絵の指示に使ってください）

| ファイル | 場面 |
|---|---|
| manga-01 | 模試の結果が返ってくる。点数を見て固まる |
| manga-02 | 見返さないまま、成績表をカバンにしまう |
| manga-03 | 次の模試。同じところをまた間違えていると気づく |
| manga-04 | 何から復習すればよいか分からず焦る |
| manga-05 | 「点数じゃなくて、落とした分野を見よう」と声をかけられる |
| manga-06 | 解説講義で間違えた理由が分かり、次の模試に向かう |

絵柄・登場人物の指定はここでは決めていません。話の流れを変える場合は
`src/config/site.ts` の `mangaSlides` の `alt` も一緒に直してください
（altは読み上げと画像読み込み失敗時の代替テキストとして実際に使われます）。

## 推奨仕様

- 形式：webp（軽量。jpg/png でも可。その場合は `src/config/site.ts` の拡張子を変更）
- 向き：縦長（スマホ向け）
- 横幅：720〜1080px 程度（横幅いっぱいに表示され、比率は自動で維持されます）
- 1枚 = 1コマ（縦に積み重ねて表示されます）

## 枚数を変える / 差し替える

`src/config/site.ts` の `mangaSlides` 配列を編集してください。
配列の要素数がそのまま表示枚数になります（追加・削除・並び替え可能）。
`asset()` はサブディレクトリ配信（/lp/moshi）用の接頭辞を付けるヘルパーです。必ず通してください。

```ts
export const mangaSlides = [
  { src: asset("/images/manga/manga-01.webp"), alt: "説明文" },
  // ...
];
```
