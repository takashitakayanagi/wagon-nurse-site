# public/images に配置する画像

現在このLPが使う画像は以下の2枚だけです。ファイルが無い場合でも
レイアウトは崩れず、中立的なプレースホルダーが表示されます
（人物やキャラクターは自動生成しません）。

| ファイル名          | 用途                                              | 仕様            |
| ------------------- | ------------------------------------------------- | --------------- |
| `wagon-point.webp`  | 指差しポーズ（ヘッダー / ファーストビュー / 最終CTA） | 正方形 320px    |
| `wagon-read.webp`   | 読書ポーズ（解決策 / 動画学習イメージ）             | 正方形 320px    |

ロゴとOGP画像は、このフォルダではなく本体サイトの
`/assets/img/wagon-logo.png` と `/assets/img/hero.jpg` を参照しています
（`src/config/site.ts` の `images` を参照）。

## 差し替えるときは

1. 最大表示サイズは112px（ファーストビュー）なので、320pxあれば十分です
2. webpに変換してから置いてください（jpg/pngのままだと20倍以上重くなります）
3. `src/config/site.ts` の `character` のパスは `asset()` を通してください。
   サブディレクトリ配信（/lp/nurse）用の接頭辞が付きます

※ WAGONちゃんの画像は正式画像のみを使用してください。
   顔・髪型をCSSやSVGで再現することはしていません。
